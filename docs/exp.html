Button Hover Comparison

Current Button (Inset Shadow)

Uses box-shadow: inset 0 0 0 100vmax color-mix(...) with hardcoded percentages.

Experimental Button (Outline-based)

Uses outline with theme-controlled variables: --hover-tint, --active-tint, --hover-outline-width.

Theme Variables (Experimental)

--hover-tint: 85%;
--active-tint: 75%;
--hover-outline-width: 2px;
--hover-outline-offset: -2px;

Benefits

  • Theme controls interaction intensity globally
  • No layout shift (outline doesn't affect box model)
  • Consistent hover/active behavior across components
  • Easy to customize per theme
