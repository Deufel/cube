Badge

Notification indicator for icons and buttons.

Base

Variants

Dot Indicator

API Reference

Classes

Class Description
badge Base (info)
badge:suc Success
badge:wrn Warning
badge:dgr Danger
dot Dot modifier

Modifiers

Modifier Description
-dot Dot indicator

Structure

/* Parent auto-gets relative positioning */
:has(> [class~="badge"], > [class*="badge:"]) {
  position: relative;
}

[class~="badge"], [class*="badge:"] {
  /* Base styles */
  
  /* Color variants */
  &[class*=":suc"] { }
  &[class*=":wrn"] { }
  &[class*=":dgr"] { }
  
  /* Dot modifier */
  &.dot { }
}

Usage

<!-- Parent auto-gets position: relative via :has() -->
<div>
  <button class="icon-btn">...</button>
  <span class="badge">3</span>
</div>

<!-- Color variant -->
<span class="badge:dgr">5</span>

<!-- Dot indicator -->
<span class="badge:suc dot"></span>
