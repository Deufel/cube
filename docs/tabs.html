Tabs

Pill-shaped tab container with active state.

Base

Variants

Sizes

Full Width

API Reference

Container

Class Description
tabs:pri Primary color
tabs:sec Secondary color

Tab Items

Direct <button> children are styled automatically

Class Description
active Active state

Modifiers

Modifier Description
-sm Small size
full Full width

Structure

[class~="tabs"], [class*="tabs:"] {
  /* Container styles */
  
  /* Variants */
  &[class*=":pri"] { }
  &[class*=":sec"] { }
  
  /* Size */
  &[class*="-sm"] { }
  
  /* Modifier */
  &.full { }
  
  /* Direct button children */
  & > button {
    /* Tab styles */
    
    &.active { /* Active state */ }
  }
}

Usage

<!-- Primary tabs with Datastar signals -->
<div class="tabs:pri" data-init="$mytab='first'">
  <button data-class:active="$mytab=='first'" 
    data-on:click="$mytab='first'">First</button>
  <button data-class:active="$mytab=='second'" 
    data-on:click="$mytab='second'">Second</button>
</div>

<!-- Full width secondary tabs -->
<div class="tabs:sec full" data-init="$status='active'">
  <button data-class:active="$status=='active'" 
    data-on:click="$status='active'">Active</button>
  <button data-class:active="$status=='archived'" 
    data-on:click="$status='archived'">Archived</button>
</div>
