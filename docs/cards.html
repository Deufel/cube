Cards

Container with padding, border, and shadow variants.

Variants

Default

Subtle primary tint.

Primary

Stronger primary tint.

Secondary

Secondary color tint.

Glass

No shadow, frosted blur.

Status Colors

Information

This is an informational card.

Success

Operation completed successfully.

Warning

Please review before proceeding.

Danger

This action cannot be undone.

Sizes

Small (40ch)

Constrained width card.

Medium (60ch)

Medium width card for moderate content.

Large (80ch)

Wide card for longer form content and detailed information.

API Reference

Classes

Class Description
card Base container
card:pri Primary variant
card:sec Secondary variant
card:gla Glass (no shadow)
card:inf Info (blue)
card:suc Success (green)
card:wrn Warning (yellow)
card:dgr Danger (red)
-sm Small (40ch)
-md Medium (60ch)
-lg Large (80ch)

Modifiers

Class Description
pri Primary tint
sec Secondary tint
gla Glass effect

Structure

[class~="card"], [class*="card:"] {
  /* Base styles */
  
  /* Sizes */
  &[class*="-sm"] { max-width: var(--card-width-sm); }
  &[class*="-md"] { max-width: var(--card-width-md); }
  &[class*="-lg"] { max-width: var(--card-width-lg); }
  
  /* Variants */
  &[class*=":pri"] { }
  &[class*=":sec"] { }
  &[class*=":gla"] { /* no shadow */ }
  &[class*=":inf"] { }
  &[class*=":suc"] { }
  &[class*=":wrn"] { }
  &[class*=":dgr"] { }
}

Usage

<!-- Base -->
<div class="card">
  <h3>Title</h3>
  <section>Content</section>
  <footer><button>Action</button></footer>
</div>

<!-- Variant + Size -->
<div class="card:pri-sm">...</div>

<!-- Status color -->
<div class="card:wrn">⚠️ Warning</div>
