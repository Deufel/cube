Cards

Container with padding, border, and shadow variants.

Variants

Default

Subtle primary tint.

Primary

Stronger primary tint.

Secondary

Secondary color tint.

Glass

No shadow, frosted blur.

With Content

Card Title

Cards are versatile containers with padding, borders, and optional shadows. Use them for grouping related content.

Featured Content

Primary variant draws attention to important content.

API Reference

Classes

Class Description
card Base container
card:pri Primary variant
card:sec Secondary variant
card:gla Glass effect

Modifiers

Class Description
pri Primary tint
sec Secondary tint
gla Glass effect

Structure

[class~="card"], [class*="card:"] {
  padding: var(--card-padding);
  border-radius: var(--card-border-radius);
  border: var(--card-border-size) solid var(--card-border);
  background: var(--surface-def);
  
  /* Variants */
  &[class*=":pri"] {
    background: var(--surface-pri);
    border-color: var(--card-pri-border);
  }
  &[class*=":sec"] {
    background: var(--surface-sec);
    border-color: var(--card-sec-border);
  }
  &[class*=":gla"] {
    background: var(--surface-gla);
    border-color: var(--card-gla-border);
    backdrop-filter: blur(var(--glass-blur-2));
  }
}

Usage

<!-- Default -->
<div class="card">
  <h3>Title</h3>
  <p>Content</p>
  <footer><button class="btn:pri">Action</button></footer>
</div>

<!-- Primary variant -->
<div class="card:pri">
  <h3>Featured</h3>
  <p>Important content</p>
</div>

<!-- Glass effect -->
<div class="card:gla">Frosted glass</div>
