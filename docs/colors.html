Light/Dark Mode

Mode is set via data-mode attribute on <html>. Datastar resolves system preference automatically.

<!-- Datastar expression resolves system preference -->
<html data-attr:data-mode="$prst_mode === 'system' 
  ? (window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light') 
  : $prst_mode">

<!-- CSS targets the attribute -->
[data-mode="dark"] {
  --shadow-color: white;
  /* dark mode overrides */
}
