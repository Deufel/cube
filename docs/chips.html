Chips

Non-interactive labels for categorization and status.

Base

Default

Theme Colors

Primary Secondary

Status Colors

Info Success Warning Danger

Modifiers

Add Add Info Sub Sub Warning Remove Remove Danger Small Rem

API Reference

Classes

Class Description
chip Base chip
chip:pri Primary (theme)
chip:sec Secondary (theme)
chip:inf Info (blue)
chip:suc Success (green)
chip:wrn Warning (yellow)
chip:dgr Danger (red)

Modifiers

Modifier Description
-sm Small size
add + prefix
sub - prefix
rem × suffix (clickable)

Structure

[class~="chip"], [class*="chip:"] {
  /* Base styles */
  
  /* Modifiers */
  &.add::before { content: "+"; }
  &.sub::before { content: "-"; }
  &.rem::after { content: "\00d7"; }
  
  /* Size */
  &[class*="-sm"] { }
  
  /* Variants */
  &[class*=":pri"] { }
  &[class*=":sec"] { }
  &[class*=":inf"] { }
  &[class*=":suc"] { }
  &[class*=":wrn"] { }
  &[class*=":dgr"] { }
}

Usage

<!-- Base -->
<span class="chip">Default</span>

<!-- Variant -->
<span class="chip:inf">Info</span>

<!-- Variant + Size -->
<span class="chip:suc-sm">Small Success</span>

<!-- Modifiers -->
<span class="chip:inf add">Add</span>
<span class="chip:wrn sub">Sub</span>
<span class="chip:dgr rem">Remove</span>
