API Reference

Flex

Class Description
flex:cluster Horizontal wrap
flex:stack Vertical column
flex:split Two items, space-between
flex:split-col Vertical split
flex:spread-row Row, space-between
flex:spread-column Column, space-between
flex:flank-start Sidebar left
flex:flank-end Sidebar right

Grid

Class Description
grid:lcr Left/center/right
grid:tmb Top/middle/bottom
grid:pancake Header/content/footer
grid:hero 3×3 app shell
grid:auto-fit Responsive columns
grid:auto-fill Responsive, keep tracks

Frame

Class Ratio
frame 1:1 (square)
frame:landscape 16:9
frame:portrait 9:16

Custom Properties

Property Used by
--flank-size flex:flank-*
--content-percentage flex:flank-*
--grid-min grid:auto-*

Usage

<!-- Sidebar layout -->
<div class="flex:flank-start">
  <nav>Sidebar</nav>
  <main>Content</main>
</div>

<!-- Fixed-width sidebar (200px) -->
<div class="flex:flank-start" style="--flank-size: 200px;">
  <nav>200px nav</nav>
  <main>Content</main>
</div>

<!-- App shell -->
<div class="grid:hero">
  <header style="grid-area: 1/1/2/-1;">Header</header>
  <nav style="grid-area: 2/1/3/2;">Nav</nav>
  <main style="grid-area: 2/2/3/3;">Main</main>
  <aside style="grid-area: 2/3/3/-1;">Aside</aside>
  <footer style="grid-area: 3/1/-1/-1;">Footer</footer>
</div>

<!-- Responsive card grid -->
<div class="grid:auto-fit" style="--grid-min: 250px;">
  <div class="card">Card 1</div>
  <div class="card">Card 2</div>
  <div class="card">Card 3</div>
</div>
