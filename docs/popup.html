Popup

Anchor-positioned popover with animations.

Base Menu

Positioning

API Reference

Classes

Class Description
popup Base container
popup:menu Menu variant
popup-item Menu item

Attributes

Element Required
Trigger popovertarget, anchor-name
Popup popover, position-anchor

Usage

<!-- Trigger -->
<button popovertarget="my-menu" style="anchor-name: --my-btn">
  Open Menu
</button>

<!-- Popup -->
<div id="my-menu" class="popup:menu" popover
     style="position-anchor: --my-btn; top: anchor(bottom); left: anchor(left);">
  <button class="popup-item">Home</button>
  <button class="popup-item">Settings</button>
  <button class="popup-item">Logout</button>
</div>
