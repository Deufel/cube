Forms

4-column grid layout with validation states. Feedback sits above inputs to prevent layout shift. Pairs with Datastar for server-side validation — classes (.suc, .dgr, .wrn) reflect backend state.

Form Layout

field:w1 (25%), field:w2 (50%), field:w3 (75%), field (100%)

Tabs in Forms

Tabs auto-match input height and support validation states.

Visibility Valid

API Reference

Container

Class Description
.form 4-column grid container

Field Elements

Element Use for
<label class="field"> Inputs, textareas
<div class="field"> Tabs (avoids click propagation)

Field Widths

Class Width
field 100% (4 cols)
field:w3 75% (3 cols)
field:w2 50% (2 cols)
field:w1 25% (1 col)

Validation States

Class State
.suc Success
.wrn Warning
.dgr Danger/Error
.inf Info

Usage

<form class="form">
  <label class="field">
    Email <span class="suc">Looks good!</span>
    <input type="email" />
  </label>
  
  <label class="field:w2">
    First Name
    <input type="text" />
  </label>
  <label class="field:w2">
    Last Name
    <input type="text" />
  </label>
  
  <button type="submit" class="w-4">Submit</button>
</form>

<!-- Tabs in form field (use div, not label) -->
<div class="field:w2">
  Status <span class="wrn">Required</span>
  <div class="tabs" data-init="$status='pending'">
    <button type="button" class="tab" 
      data-on:click="$status='pending'" 
      data-class:tab:active="$status=='pending'">Pending</button>
    <button type="button" class="tab" 
      data-on:click="$status='active'" 
      data-class:tab:active="$status=='active'">Active</button>
  </div>
</div>

Tips

Mobile Keyboard Hints

Use enterkeyhint to control the Enter key label: next, done, search, go, send

Use inputmode for the right keyboard: tel (phone pad), decimal (numbers + decimal)

Validation Attributes

required, maxlength, minlength, pattern, min/max

Autofill Hints

autocomplete="email", "tel", "postal-code", "given-name", "family-name", "street-address"

Enter Key Navigation (Datastar)

<input enterkeyhint="next"
  data-on:keydown="if(evt.key==='Enter'){
    evt.preventDefault();
    el.closest('[class*="field"]')
      .nextElementSibling
      ?.querySelector('input,textarea')
      ?.focus()
  }" />
