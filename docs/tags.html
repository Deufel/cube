Tags

Non-interactive labels for categorization and status display.

Base

Default tag with primary tint.

Default

Variants

Status variants using tag:variant pattern.

Info Success Warning Danger

Removable

Add .close span for dismissible tags.

Default × Info × Success × Warning × Danger ×

API Reference

Selectors

Class Description
tag Base tag, primary tint
tag:inf Info (blue)
tag:suc Success (green)
tag:wrn Warning (yellow)
tag:dgr Danger (red)

Modifiers

Modifier Description
-sm Small size (append to variant)

Inner Elements

Class Description
.close Dismissible close button

Usage

<!-- Base -->
<span class="tag">Default</span>

<!-- Variant -->
<span class="tag:inf">Info</span>

<!-- Variant + Size -->
<span class="tag:suc-sm">Small Success</span>

<!-- Removable -->
<span class="tag:dgr">Error <span class="close">×</span></span>
