Surface

Well-based surface system with automatic elevation. Uses CSS :has() to detect nesting — deepest containers get darkest shade, leaf surfaces (containing no other surfaces) get lightest for optimal readability.

Basic Usage

Surfaces inside a colored card inherit and lighten the card's hue.

card.pri
surface (leaf)
surface (leaf)

Nested Surfaces

Nesting automatically darkens parent surfaces while keeping leaves lightest.

card.pri (sets --_surface-base)
surface (parent) — darker
surface (leaf) — lightest

Three Levels Deep

Maximum supported depth: grandparent → parent → leaf.

card.sec
surface (grandparent) — darkest
surface (parent) — mid
surface (leaf) — lightest

Shadow Modifier

Add .shadow for elevation depth cues.

Without shadow
surface
With shadow
surface shadow

API Reference

Theme Tokens

Token Description
--surface-1 Deepest (page)
--surface-2 Mid elevation
--surface-3 Content (lightest)
--_surface-base Set by card variants

Classes

Class Description
.surface Auto-lightens based on nesting
.shadow Adds box-shadow

Usage

<!-- Card sets the surface base -->
<div class="card pri">
  <div class="surface shadow">Leaf surface</div>
</div>

<!-- Nested surfaces auto-elevate -->
<div class="card sec">
  <div class="surface">
    Parent (darker)
    <div class="surface">Leaf (lighter)</div>
  </div>
</div>

<!-- Three levels deep -->
<div class="card pri">
  <div class="surface">
    Grandparent (darkest)
    <div class="surface">
      Parent (mid)
      <div class="surface">Leaf (lightest)</div>
    </div>
  </div>
</div>
