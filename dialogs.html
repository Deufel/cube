Dialogs & Drawers

Modal dialogs and slide-out drawer panels.

Centered Dialog

Native <dialog> with .showModal() for focus trapping and backdrop.

Drawers

Slide-out panels using drawer:direction classes.

API Reference

Dialog

Element Description
<dialog> Native dialog element, styled automatically
::backdrop 50% opacity dark overlay (no blur)

Drawer Classes

Class Description
drawer:left Slides in from left
drawer:right Slides in from right
drawer:top Slides in from top
drawer:bottom Slides in from bottom

Usage

<!-- Centered Dialog -->
<dialog id="my-dialog">
  <div class="card flex:stack gap:sm p:md">
    <h2>Dialog Title</h2>
    <p>Dialog content here.</p>
    <button data-on:click="this.closest('dialog').close()">Close</button>
  </div>
</dialog>

<!-- Drawer -->
<dialog id="my-drawer" class="drawer:left">
  <div class="card gla flex:stack gap:sm p:md">
    <h2>Drawer Title</h2>
    <button data-on:click="this.closest('dialog').close()">Close</button>
  </div>
</dialog>

<!-- Open with Datastar -->
<button data-on:click="document.getElementById('my-dialog').showModal()">
  Open Dialog
</button>
