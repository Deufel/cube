Dialogs & Drawers

Modal overlays for focused content and slide-out panels.

Dialog

Centered modal with darkened backdrop. Uses native <dialog> element.

Dialog Title

This is a centered dialog with a simple darkened backdrop (no blur) and shadow.

Left Drawer

Slide-out panel from the left edge. Uses drawer:left class.

Left Drawer

This drawer slides in from the left.

Right Drawer

Slide-out panel from the right edge. Uses drawer:right class.

Right Drawer

This drawer slides in from the right.

API Reference

Dialog

Element Description
<dialog> Native dialog element, auto-styled with shadow and backdrop

Drawer Classes

Class Description
drawer:left Slides in from left edge
drawer:right Slides in from right edge

JavaScript API

Method Description
.showModal() Open dialog with backdrop
.close() Close dialog

Usage

<!-- Dialog -->
<button onclick="document.getElementById('my-dialog').showModal()">Open</button>

<dialog id="my-dialog" class="p:md">
  <h3>Title</h3>
  <p>Content here...</p>
  <button onclick="this.closest('dialog').close()">Close</button>
</dialog>

<!-- Drawer (using popover) -->
<button popovertarget="my-drawer">Open Drawer</button>

<dialog id="my-drawer" class="drawer:left" popover="manual">
  <div class="drawer-content p:md">
    <h3>Drawer Title</h3>
    <button popovertarget="my-drawer">Close</button>
  </div>
</dialog>
